## 概念卡 6：单链表增删心法

**是什么**：链表的"连接"从来不是两个节点相连，而是改某一条指针的指向——头节点由 head 变量负责，其余节点由前驱的 next 负责。
**为什么**：尾插找尾必须停在最后一个节点（`while (ptr->next != NULL)`），因为要改的是它的 next；删除必须持有前驱，因为单向链表只能从前面那条指针上把节点摘下来。
**我代码里的位置**：`parts/08_rewrite_list/list.c` 的 `append_to_tail`（先找尾再 `ptr->next = new_node`）、`delete_node`（`prev == NULL` 判头、`prev->next = cur->next` 判中）、`free_all`（先存 next 再 free）。
**易错点**：尾插条件写成 `ptr != NULL` 直接走出链尾；删除时先 `free(cur)` 再取 `cur->next`（use-after-free）；`free_all` 忘了先保存 next，断链漏释放；删除成功后没 return，继续用已释放的 cur。
**面试追问**：
- 问：尾插为什么用 `ptr->next != NULL` 而不是 `ptr != NULL`？
  答：要找的是最后一个节点本身（它的 next 为 NULL），停在那里才有可写的 next 接上新节点；写成 `ptr != NULL` 会走到 NULL，那时已经没有 next 可改了。
- 问：删除为什么非要 prev，能不能只用一个指针？
  答：单向链表只有 next，摘链必须改前驱的 next。单个指针只能做"偷内容"式删除（把后继内容拷过来再删后继），尾节点就失效了，正解是双指针或二级指针。
