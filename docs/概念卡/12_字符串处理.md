## 概念卡 12：字符串比较 / 查找 / 切分

**是什么**：C 字符串是"以 `\0` 结尾的字符数组"，数组名和指针本身只是地址，所以比内容用 strcmp、判是不是同一块内存才用 `==`；strchr/strstr 返回的是指针，改它指向的那个字节就等于原地改字符串。
**为什么**：`\0` 既是字符串的结束标志，也正好能当切分的刀——把分隔符改写成 `\0`，就把一段内存零拷贝地切成两段（前半段本来就已经是合法字符串），不用另分配内存，在资源受限的嵌入式里比 strdup 或 strtok 省得多。
**我代码里的位置**：`parts/06_config/step2_parse.c`：`strchr(line, '\n')` 去行尾换行；`line[0] == '#'` 跳注释；`strchr(line, '=')` 找到等号后写一个 `*eq = '\0'`，于是 line 是 key、`eq + 1` 是 value。
**易错点**：用 `==` 比字符串内容（比的是地址，永远不等）；strcmp 返回 0 才表示相等，写成 `if (strcmp(a, b))` 意思正好相反；忘了 strchr 可能返回 NULL（没有分隔符的行）就去解引用；写字符串字面量（`char *s = "..."` 在只读区，改它会段错误，必须用 `char s[]`）；把 `\0` 写到缓冲区边界外。
**面试追问**：
- 问：`*eq = '\0'` 为什么能切出两段，需要拷贝吗？
  答：不需要。等号位置改成 `\0` 后，行首到等号自然变成一个字符串，`eq + 1` 就是 value 的起点，两块数据还躺在同一段缓冲区里，零拷贝。代价是原行被破坏，之后不能再当完整行用。
- 问：什么时候必须 strcmp，什么时候 `==` 是对的？
  答：判内容相等必须用 strcmp，它比的是内存里的字节；判"是不是同一个对象/同一个地址"（空指针判断、按指针做表项比对）才用 `==`。另外 strcmp 返回 0 表示相等，别当布尔真用反了。
