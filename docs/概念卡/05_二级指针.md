## 概念卡 5：二级指针

**是什么**：二级指针是"存放指针的那个变量的地址"。形参写成 `struct node **head` 时，`head` 是调用方头指针变量的地址，`*head` 就是那个头指针本身（第一个节点的地址）。
**为什么**：C 只有值传递，形参永远是拷贝。函数如果要修改调用方的头指针变量本身（比如头插、删掉首节点），就必须拿到这个变量的地址，所以传 `&head`；只读写节点内容时一级指针就够。
**我代码里的位置**：`parts/08_rewrite_list/list.h` 里 `append_to_tail(struct node **head, int id)` 和 `delete_node(struct node **head, int id)`；对照 `print_list(struct node *head)` 只遍历不改头，用一级指针。
**易错点**：以为传了指针调用方的 head 就会变；函数里写 `head = new_node`（改的是拷贝）；空链表时没判 `*head != NULL` 就去碰 `(*head)->next`；需要改指针本身时误用一级指针。
**面试追问**：
- 问：为什么删除头节点必须用二级指针，删中间节点却不用？
  答：中间节点能靠前驱改到链上（`prev->next = cur->next`），头节点没有前驱，唯一指着它的是调用方那个 head 变量，只能拿它的地址去改，所以要二级指针。
- 问：`*head` 摸到的到底是哪块内存？
  答：是调用方栈上那个 head 变量本身，它的值是第一块节点的地址。写 `*head = x` 就是在改调用方的 head。
